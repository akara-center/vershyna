# Вершина

[Повний паспорт продукту й проєкту та інструкції керування](docs/PASSPORT.md).

Персональний гейміфікований трекер: проєкти, задачі, підкроки, XP, нагороди, таймер, архів та кошик.

Статичний HTML/CSS/JavaScript. Немає залежності від ChatGPT чи платних API.

## GitHub Pages

Settings → Pages → Source: GitHub Actions. Workflow `.github/workflows/pages.yml` перевіряє код і публікує `dist/`.

Опублікований застосунок: https://akara-center.github.io/vershyna/.

## Особисті дані

Новий браузер стартує з порожнім списком. Дані → імпорт JSON → перевірити → підтвердити заміну. Дані лишаються в localStorage цього браузера; автоматичної синхронізації між пристроями немає. JSON не потрібно додавати в репозиторій.

Дані старого домену не переходять автоматично на новий. Старий застосунок збережений на час перенесення. Збережіть JSON перед зміною адреси.

## Файли та перевірки

- dist/index.html — HTML-каркас і підключення.
- dist/styles.css — стилі, адаптивність і теми.
- dist/app.js — інтерфейс, збереження, імпорт і копії.
- dist/quest-core.js — дерево, прогрес, XP, архів і кошик.
- dist/initial.js — порожній початковий стан і підтримка старих форматів.
- tests — регресійні перевірки.

Запуск: `node --test tests/*.test.cjs`. Локальний перегляд: `python3 -m http.server 8000 --directory dist`.

## Резервні копії

Копії показують дату й час за Києвом; файли експорту мають дату в назві (UTC). Перший запуск оновлення з наявним прогресом створює одну копію перед перенесенням та лише після успішного запису видаляє старі локальні копії. Повторне відкриття не перезаписує цю копію. Подальші захисні копії перед імпортом, перенесенням задач і операціями з кошиком також датовані.

Прогрес не зберігається на GitHub. Очищення браузерних даних видаляє локальний прогрес і копії; зберігайте JSON окремо.
