# Робота над Вершиною

Перед змінами читати README.md, docs/PASSPORT.md та відповідний код. Паспорт є поточним описом продукту й управління; після поведінкової зміни актуалізувати відповідний розділ. Не скидати особистий localStorage і не додавати JSON прогресу в Git. Ієрархія, XP, кошик на 7 днів, скасування завершення лекції мають зберігатися. Не плутати автоматичне закреслення, остаточну галочку, архівування й видалення. Усі діалоги закриваються тапом зовні. Видалення задачі/підкроку — через ⋯ з підтвердженням. Резервні копії мають дату. Перевіряти node --test tests/*.test.cjs та браузерні сценарії відповідно до зміни. Статуси повідомляти фактично. Не публікувати особисті дані.
